# GoFixAfrica 🔧

Africa's trusted platform connecting car owners with verified mobile mechanics.

![GoFixAfrica](https://img.shields.io/badge/GoFixAfrica-Automotive%20Marketplace-orange)
![Status](https://img.shields.io/badge/Status-In%20Development-blue)
![License](https://img.shields.io/badge/License-Proprietary-red)

## 🌍 Overview

GoFixAfrica is a pan-African automotive services marketplace that connects:
- **Car Owners** seeking reliable repair and maintenance services
- **Verified Mechanics** offering mobile and workshop services
- **Parts Vendors** selling genuine auto parts

## 🚀 Features

### For Customers
- 📍 Location-based mechanic discovery
- ⭐ Multi-source reputation scoring
- 📱 WhatsApp-first booking
- 💳 M-Pesa & mobile money payments
- 🔒 Verified mechanic network

### For Mechanics
- 💼 Flexible work scheduling
- 💰 60% commission model
- 📈 Reputation building system
- 🔧 Parts vendor network access
- 📊 Job management dashboard

### For Vendors
- 🏪 Digital storefront
- 🤝 Direct mechanic connections
- 📦 Order management
- 📍 Multi-location support
